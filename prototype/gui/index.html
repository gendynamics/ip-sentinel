    Verification package

    One self-contained JSON file with every block, every file hash, and the steps a third party needs to check the chain without access to this computer. File contents are never included, only their fingerprints.

    Timestamps come from this machine's clock.

    The chain proves your records weren't edited and the order they were made in. To make the dates verifiable by a third party, anchor the head hash with an independent service such as an RFC 3161 timestamp authority or OpenTimestamps.

    How a third party verifies this package
    1. For each block, drop the block_hash field and serialize the rest as JSON with sorted keys, separators (',', ':'), UTF-8 encoding and non-ASCII characters left unescaped.
    2. The SHA-256 hex digest of those bytes must equal the block's block_hash.
    3. Block 0's previous_block_hash is 64 zeros; every later block's must equal the prior block's block_hash.
    4. To prove a file's contents existed by a block's timestamp, compute the file's SHA-256 and find it in that block's entries.
